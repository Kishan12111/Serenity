# Serenity - Quick Start Guide

## Getting Started in 30 Seconds

### 1. Open the App
Click the preview or deploy to start using Serenity immediately. No login needed!

### 2. Set Your First Timer
- Go to the **Focus** tab
- Choose a duration: 25 minutes is recommended for your first session
- Click **Start** or press **Spacebar**

### 3. Watch It Work
- See the circular progress ring fill up
- Notice the breathing animation
- Take a break when the timer completes

### 4. Check Your Progress
- Go to **Stats** to see your first focus session recorded
- Watch your daily total increase
- Celebrate completing your first session!

---

## First Session Tips

### Recommended Setup
1. **Environment**: Minimize distractions
   - Close unnecessary tabs/apps
   - Put phone in another room
   - Choose a calm wallpaper

2. **Duration**: Start with 25 minutes
   - Use the built-in Pomodoro duration
   - Or set a custom time you're comfortable with

3. **Break**: Take 5 minutes after
   - Stand up and stretch
   - Get water
   - Step away from the screen

4. **Track**: Check stats after 3-5 sessions
   - See your total focus time
   - Notice the pattern
   - Adjust as needed

## Common Scenarios

### Scenario 1: "I want a quick 15-minute session"
1. Click the **15m** button
2. Press **Start** (or Spacebar)
3. Done! Check stats after

### Scenario 2: "I need longer focus time"
1. Type a custom duration (60, 90, 120 minutes)
2. Click **Start**
3. It'll reset if you pause

### Scenario 3: "I want to try Pomodoro"
1. Click the **Pomodoro Mode** button
2. It'll auto-cycle: Focus → Break → Focus → Break...
3. After 4 sessions, you get a long break
4. Perfect for structured work!

### Scenario 4: "My stats are missing"
- **Check**: LocalStorage is enabled in browser
- **Remember**: Data only persists on this device
- **Solution**: Use the same device + browser

### Scenario 5: "I broke my streak"
- **Don't worry!** It resets automatically
- **Recovery**: Do a session today to restart
- **Better luck next time**: Build it back up!

## Pomodoro Technique Explained

Serenity uses the Pomodoro method - scientifically proven to boost focus:

```
Session 1: Focus (25m) → Break (5m)
Session 2: Focus (25m) → Break (5m)
Session 3: Focus (25m) → Break (5m)
Session 4: Focus (25m) → LONG BREAK (15m)
Session 5: Focus (25m) → ... cycle repeats
```

**Why it works:**
- Short sessions prevent burnout
- Regular breaks refresh your mind
- Longer breaks reward consistency
- Clear rhythm improves focus

**Customize it:**
- Go to **Settings**
- Adjust Focus Time, Short Break, Long Break
- Save automatically when you change values

## Troubleshooting

### "My data disappeared"
**Cause**: Browser cache cleared or incognito mode
**Solution**: Use same browser in normal mode

### "Timer keeps pausing"
**Cause**: Might be browser sleep settings
**Solution**: Keep tab active, adjust OS sleep settings

### "Wallpaper doesn't change"
**Cause**: Selection didn't save
**Solution**: Try selecting again in Settings tab

### "Charts not showing"
**Cause**: No stats recorded yet
**Solution**: Complete a focus session first

### "Keyboard shortcut not working"
**Cause**: Focus might be on input field
**Solution**: Click the timer area first, then press spacebar

## What Gets Saved

✅ **Saved locally** (your device only):
- Daily focus statistics
- Streak information
- Wallpaper preference
- Animation settings
- Pomodoro durations

❌ **NOT saved**:
- Never sent to servers
- No cloud sync (keep on same device)
- Cleared if cache is wiped
- Not available in incognito mode
